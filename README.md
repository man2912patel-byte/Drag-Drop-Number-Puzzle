# 🎯 Find The Secret Number

A fun and interactive **Drag & Drop Number Guessing Game** built using **HTML, CSS, and JavaScript**.

## 📌 Features

- 🎲 Random secret number generated between **1 and 100**
- 🖱️ Drag and Drop gameplay
- ⬆️ "Go Higher" hint
- ⬇️ "Go Lower" hint
- 🎉 Win popup on correct guess
- 🔢 Attempt counter
- 🔄 Automatic game reset after winning
- 📱 Responsive UI
- ✨ Modern glassmorphism design

## ▶️ How to Play

1. Open the game in your browser.
2. Drag any number (1–100).
3. Drop it into the **Drop Here** box.
4. Follow the hints:
   - ⬆️ Go Higher
   - ⬇️ Go Lower
5. Keep guessing until you find the secret number.
